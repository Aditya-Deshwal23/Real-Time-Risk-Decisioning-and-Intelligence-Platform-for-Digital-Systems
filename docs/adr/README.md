# Architecture Decision Records

**Responsibility:** Index and store architecture decisions that extend or change the approved architecture.

**Must never contain:** Decisions that contradict the frozen architecture without owner approval, or decisions numbered below ADR-021.

**First implementation phase:** Phase 1 — Empty repository to professional monorepo.

ADR-001 through ADR-020 are recorded in [`../context/architecture.md`](../context/architecture.md). New records start at ADR-021 and use [`ADR-TEMPLATE.md`](ADR-TEMPLATE.md).
