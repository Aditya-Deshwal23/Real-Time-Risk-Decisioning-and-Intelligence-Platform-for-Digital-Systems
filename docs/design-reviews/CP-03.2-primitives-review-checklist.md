# CP-03.2 primitive review checklist

## Purpose

Use this checklist for every primitive review.

- [ ] A named shell, Phase 4 or Phase 5 consumer exists.
- [ ] Public props are typed and exported from `console/src/components/ui/index.ts`.
- [ ] Default, hover, focus-visible, active, disabled, loading, error and empty states are shown where applicable.
- [ ] Light and dark themes are shown.
- [ ] The component uses semantic tokens only.
- [ ] Native markup or Radix supplies keyboard and ARIA behavior.
- [ ] No hand-rolled focus trap, roving tabindex or ARIA wiring exists.
- [ ] Status and severity include text and an icon.
- [ ] Field errors use `aria-describedby` and visible text.
- [ ] Dialog focus enters the dialog and returns to the trigger.
- [ ] Tooltip is focusable, dismissible and persistent on hover/focus.
- [ ] Toast success/info is polite; error persists until dismissed.
- [ ] Table and code regions are focusable and labelled.
- [ ] Code and table cells render text only.
- [ ] Copy failure and success are handled without logging values.
- [ ] No primitive imports app, feature or API internals.
- [ ] No app or feature deep-imports a primitive file.
- [ ] The Storybook build and component tests pass.
